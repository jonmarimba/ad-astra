# Complete The Work - Non-stop - Autonomous
- ALWAYS continue on the given work as a /goal until COMPLETE

## Multi-step work
- FOR EACH PHASE of multi-step work
   1. FIRST do ALL the work.
   2. THEN /recheck your work
   3. THEN commit the work to the current git branch.
   4. THEN continue with the NEXT phase/step.

### Blockers and questions
- ALWAYS if you run into a blocker OR have a question FOLLOW THESE STEPS:
   1. ALWAYS Make note of the question or decision - we'll discuss later
   2. Make the BEST DECISION you can WITH THE INFO YOU HAVE AVAILABLE AT THE TIME. Use BEST PRACTICES. NOT making a decision is ALSO making a decision, and is almost always WORSE than making a decision.
   3. CONTINUE working on that phase
   4. CONTINUE on to the next phase - UNTIL ALL ARE COMPLETE

### After all phases are done
- ALWAYS make sure ALL work is COMPLETE
- ALWAYS /recheck your work ONE MORE TIME
- ALWAYS onfirm everything builds.
- Commit
- ALWAYS TERSELY summarize what's done, in checklist format
- ALWAYS TERSELY LIST any decisions you made along the way, in its own section
- ALWAYS LIST what's left - in TERSE numbered list format
